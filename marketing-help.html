Quick start

  1. Sign in to THORE Pulse and choose Marketing Workflow from your profile menu (the same login works).
  2. The Overview tab shows what needs your attention. Board shows active campaigns by step. Projects lists every project. Tasks holds day-to-day tasks. Admins also see Approved Campaigns and Team Performance.
  3. Click any campaign to open it. Everything you can do is on that panel.
  4. The page refreshes itself every 20 seconds. The 🔔 bell shows what changed.
  5. Press 🙋 My Pending Work in the filter bar to see only the campaigns waiting for you.
You only see your own work: executives see their campaigns, the designer sees campaigns currently with him, zone approvers see their zones. The manager and head see everything.

The 9 steps of a campaign

Brief → Design → Executive Review → Content → Manager approval → Final approval → Approved → Setup Done Check → Completed

Work can be sent back from the approval steps. A comment is always required when sending back. Awareness campaigns end earlier: manager approval completes them (steps 6–8 are skipped). A campaign can also be put On hold or Cancelled by the manager or head.

Whenever a manager or zone approver asks for changes, the campaign goes back to Executive Review. The Executive decides whether the designer is needed.

1 · Brief Executive

Write the objective, audience, offer and format. Add the Video / Reel link (optional) if there is a reference video for the designer. Use Save draft if you need to continue later. When ready, click Send to designer. A designer must be assigned first.

The video / reel link shows as a clickable link on the campaign panel, so the designer can open it with one click. Any web address typed inside the brief text is clickable too.

2 · Design Designer

Read the brief, open the video / reel link if there is one, and read the project key points. Choose the file, write what changed, click Upload new version, then Submit creative. Every upload is a new version; nothing is overwritten.

You can only submit after uploading at least one file. For an optimization, the file must be uploaded after the optimization started.

3 · Executive Review Executive

Open the creative files. Click Accept creative to continue to Content, or Send to designer for changes (with a comment) to send it back to the designer.

This is also where a campaign lands when the manager or the zone approver asks for changes. Read their comment in the campaign History, then either continue yourself (Accept creative → update Content) or send it to the designer only if the creative itself must change.

4 · Content Executive

Write the ad texts, headlines, call-to-action and link. Save draft as you go. Click Submit for approval when done.

5 · Manager approval Manager / Head

Check the creative and content. Approve, send to zone approver, or click Send back to Executive Review with a comment. You cannot approve a campaign where you are the executive.

6 · Final approval Zone approver

The zone approver sees an orange Approval Pending tag. Choose Final approve or Send back to Executive Review with a comment. If a zone has no approver set, the campaign cannot reach this step.

7 · Approved Executive

Set the campaign up in the ad platform. Write the platform and campaign link in the setup box, then click Mark setup done.

8 · Setup Done Check Manager / Head

Check the live setup. Click Mark completed, or Return for fixes with a comment.

9 · Completed

The campaign is finished and stays in the system, but it is no longer shown on the Board. If it needs changes later, the manager or head can create an optimization request on it, or use Suggest changes from Approved Campaigns.

Overview

  • Needs your attention lists only the campaigns waiting for you (the number is shown in the heading). If there are more than 12, press Show all in Board.
  • Pipeline shows every active campaign by step.
  • By Project shows, for each project, a progress bar and the number of campaigns in each step (for example Design 2, Content 1, Completed 4).
  • The cards at the top count campaigns by step, overdue campaigns and open tasks.

Board

  • Columns show campaigns by step. Completed and Cancelled campaigns are not shown on the Board; find them in Projects.
  • Each card shows the assigned date (the day the campaign was created) and how many days old it is, so you can spot old campaigns quickly.
  • Use 🙋 My Pending Work to see only the cards waiting for you.

Projects & status

The old “Requests” section is now Projects. Nothing is ever deleted. A project is Active, Completed or Cancelled.

  • All screens show Active projects by default. Use the Project Status buttons in the filter bar to include Completed and Cancelled ones.
  • Click a project name to open it. The project's key points and all its campaigns (with status and executive) show only when the project is open.
  • Make Project Completed (Head): only when every campaign is completed or cancelled.
  • Mark Project Cancelled (Head): needs a reason and cancels all unfinished campaigns. Completed campaigns stay as they are.
  • Reactivate project (Head) brings a completed or cancelled project back to Active.

Create a new request Manager / Head

Open Create → New Request.

  1. Project: pick zone, cluster, city, and search the project name. The developer fills in by itself. Set one deadline for the whole project.
  2. Configurations and prices: add one row per configuration with area and price.
  3. Key points: the box already has headings (Location / Locality, USPs, Target audience, Nearby locality highlights, Key features of the project). Type after each heading.
  4. Lead generation Campaigns (section 4): pick sub type (Focused / Generic), type, targeting and region, enter the number and click Add to list. Selecting several in each group adds every combination at once. Domestic campaigns need no region.
  5. In the list, choose the executive and designer for each line (or “Set for all lines”). You can leave them for later.
  6. Check the names. Under the list, every campaign has its name already created. Click ✏️ Change to type a different name; Reset brings the automatic name back. See Campaign names.
  7. Awareness Campaigns (section 5) work the same way. They are named with Awareness at the end, and they only go up to manager approval — after that they are marked Completed straight away (no zone approval or setup steps).

How campaigns are named

Name = THORE IH + project + Focused (only for Focused) + type + region (not for Domestic).

  • Focused, NRI: THORE IH Mahindra Baner NX Focused Reel Delhi
  • Awareness: THORE IH Mahindra Baner NX Focused Reel Delhi Awareness, and with several: … Awareness 1, … Awareness 2
  • Several of the same kind get plain numbers: THORE IH Mantra Melange Wadgaon Sheri Video 1, … Video 2, … Video 3 (no leading zero)

Changing a name while creating

In New Request and in Edit / add campaigns, each campaign in the list shows its automatic name with a ✏️ Change button (for lead generation and awareness campaigns). Type the name you want and click outside the box. Changed names turn blue. The names are applied as soon as the campaigns are created, so you do not need to open each campaign afterwards. Two campaigns in a project cannot have the same name.

Changing a name later

The manager or head can still rename any campaign: open it and use Campaign name → Save name. Every rename is recorded with the person's name and time.

Edit a project and add campaigns Manager / Head

On an Active project click Edit / add campaigns.

  • You can change configurations, prices, key points, cluster, city and deadline. The new details show on every campaign of that project straight away.
  • If configurations or prices change, campaigns already waiting for approval or later go back to Content so they are approved again with the right details.
  • Use sections 4 and 5 to add more campaigns to the same project. New campaigns show the same automatic names with a ✏️ Change button. Numbering continues after the existing campaigns. Adding campaigns to a Completed project reopens it.
  • Every edit is saved in the history with the name of the person and the time.

Optimization (changing a live campaign) Manager / Head

Use it when a live campaign needs new content, a new design, or both. Start from Create → New Optimization, or open a completed campaign and click Create optimization request.

  • Campaign in the system: search a completed campaign by name.
  • Campaign not in the system: type its project and name. If the project exists, the campaign is added to it; otherwise a new project is created.
  • Tick Change content, Change design or Both, and write the changes. Choose the executive and designer (the old ones are pre-selected).

What happens next

  • Design changes go to the designer first, then the executive reviews the creative, then (if content also changes) the executive updates the content, then the manager approves.
  • Content-only changes go to the executive, then to the manager for approval.
  • On manager approval, the campaign is closed again (Completed). Final zone approval and setup are not repeated.
  • The campaign gets an Optimized - 1 / 2 / 3… tag before its name, and every round is listed under “Optimization history” in the campaign panel. All activity stays on the same campaign.

Tasks

Managers and heads create tasks from Create → New Task (or the “+ New task” button in Tasks): title, details, person, Important / Urgent, and one-time or repeating (daily, weekly on a weekday, monthly on a date).

  • Priority matrix: open tasks in four boxes — Important-Urgent, Important-Not urgent, Not important-Urgent, Not important-Not urgent.
  • Board: New → Started → Manager review → Completed, plus Cancelled. Assignees start a task and send it for review; the manager completes it or sends it back with a comment.
  • History: all finished tasks by date with the time taken, and the list of repeating tasks (with a Stop button).
  • Repeating tasks create that day's task automatically when someone from the team opens the system.

Filters

Overview, Board and Projects share one filter bar: Zone, Cluster, City, Project, Developer, Executive, Campaign, Campaign Type, Targeting, Objective and Project Status.

  • Click a box and type the first 2–3 letters, then pick from the list (or press Enter to take the first match).
  • Clear a single filter with its × chip, or use Clear for all.

🙋 My Pending Work

The orange button on the second row shows only the campaigns that are waiting for you right now — for example Executive Review for the executive, Manager approval for the manager, Final approval for the zone approver. The number on the button is how many there are. Press it again to switch it off. It works together with the other filters.

Approved Campaigns Admin only

The ✔️ Approved Campaigns tab (after Board) lists every campaign that has received approval, with:

  • the campaign name (click it to open),
  • the project and zone,
  • who approved it and when,
  • the current stage of the campaign.

Use the search box to find a campaign or project.

Suggest changes Manager / Head

The manager or head can click ✏️ Suggest changes on a campaign that is Approved, in Setup Done Check or Completed.

  1. Write the changes needed in the box (required).
  2. Click Send to zone approver. The campaign moves back to Final approval, and the comment is saved in its History.
  3. The zone approver reads the comment and uses Send back to Executive Review.
  4. The Executive makes the changes, and the campaign goes through approval again.
Suggest changes is only for the Marketing Head and Manager. Admins who are not head or manager can view the list but do not see the button.

Updates, bell and sound

  • The page refreshes every 20 seconds; “Updated hh:mm:ss” in the header shows the last refresh. It never overwrites text you are typing.
  • A small pop-up appears when someone else changes a campaign you can see, or sends you a task. Click it to open the item.
  • A soft two-tone sound plays with the pop-up, only while the page is open and visible. Turn it off or on from your profile menu → Sound.
  • The 🔔 bell lists the latest 30 campaign updates. New ones carry a blue NEW tag; after you open the bell they count as seen.
Browsers only allow sound after you have clicked somewhere on the page once.

Files

  • Creative files can be images (jpg, png, webp), mp4 videos or pdf. The maximum size is shown above the file box (currently 20 MB); the system owner can change it.
  • Files are stored in Supabase for now and may move to Oracle cloud storage later. Files uploaded earlier keep opening normally after a move.
  • Click a file name to open it in a new tab. Every upload is a new version and nothing is deleted.

History, audit trail and export

  • Every change is recorded with who and when: status moves, comments, assignments, edits to project details, file uploads and task changes. Nobody — including admins — can edit or delete these records.
  • Open a campaign: History shows the steps and comments; Audit trail shows every recorded change.
  • On Projects, Export with full history downloads a JSON file with all data and a CSV file of the complete history for that project.

Team Performance Admin only

Shows, for each executive and the designer: campaigns assigned, in progress, on hold and completed in the chosen period; average cycle time; average time in each step (Brief, Exec review, Content, Setup, Design); how often work was sent back; tasks assigned, completed, average time and on-time percentage; and actions recorded on each of the last 7 days.

Times are elapsed clock time (including nights and weekends), not working hours. Campaigns created before this release have approximate start times.

Stuck? Common questions

I cannot see a campaign I expected.

Executives see only their own campaigns, and the designer sees only campaigns currently in Design. Check the Project Status filter, and check that My Pending Work and the date filter are switched off. Completed and cancelled campaigns are not on the Board; look in Projects.

A button is missing.

Buttons appear only for the person whose turn it is. The campaign panel's status chip shows the current step; use “Help for this stage”.

“You cannot move this campaign…”

Check: designer assigned (Brief), a file uploaded (Design), content written (Content), setup note written (Approved), a comment written when sending back, and that you are not approving your own campaign.

My name change did not apply.

A name must be unique inside its project. If a name could not be applied, a message appears; open the campaign and use Campaign name → Save name.

Upload fails.

Files must be within the size limit shown above the file box and be jpg, png, webp, mp4 or pdf. Compress large videos first. If the message mentions the browser blocking the upload, tell the Operations team.

No sound.

Click anywhere on the page once, check profile menu → Sound is On, and make sure the tab is open and visible.
