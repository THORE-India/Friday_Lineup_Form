NAVIGATION

Using the tool

Seven quick steps to find your work and act on it.

1 · Sign in

Open the Marketing Workflow page and sign in with your authorised account. An active THORE PULSE session may log you in automatically.

2 · 📊 Overview

Check campaign counts, current stages, pending actions and overdue work.

3 · 🗂️ Board

Campaigns grouped by status. Open a card to see details and your available actions.

4 · 📁 Requests

Review project requests and the campaigns created under each.

5 · Campaign panel

Brief, content, creative files, comments and activity history all live here.

6 · Take action

Use the buttons shown: submit, accept, request changes, approve, mark setup done or complete. You only see buttons for your role and status.

7 · 🔔 Stay updated

Check the bell and refresh the page regularly for new activity.

➕ New Request (Head/Manager)

Pick zone, cluster, city, project and developer; add deadline, selling points, configurations and prices; choose campaign types (Reel, SV, Interior, Elevation, Floor Plan, AI video), targeting (NRI, Outstation, Domestic) and regions; assign executive and designer.

On hold or cancelled?

Managers and Heads can Put on hold (then Resume) or Cancel campaign. A reason is recorded, so use these only through the authorised process.

Before you submit

Rules everyone must follow

Use the system as the record

Briefs, content, creatives and setup details stay attached to the campaign.

Follow the sequence

Never start setup before zone approval is complete.

Keep revisions traceable

Upload revised creatives to the campaign instead of sharing files privately.

Explain every return

Write a clear, actionable comment whenever you request changes.

Protect deadlines

Review Overview and Board regularly; handle overdue campaigns first.

Confirm completion properly

Only the final reviewer’s “Mark completed” closes a campaign.

FAQ

I can’t see any action button.

Buttons appear only when the campaign is at your stage and you are the person responsible. Check the Status guide to see who it is waiting on.

The approver sent my campaign back. What now?

Read the comment on the campaign. Creative problems return to the Designer (Design status); copy or pricing problems return to the Executive (Content status). Fix, then resubmit through the same approval path.

Can I start the ad setup once the manager approves?

No. Wait for zone approval; the campaign must reach Approved.

What file types can the designer upload?

Images, MP4 videos and PDFs, subject to the tool’s upload size limits.

Who approves my zone?

Pune and South: Sandeep Sonawane Sir. Mumbai: Onkar Patil Sir. The system routes this from the zone on the request.

I marked setup done but it isn’t Completed.

That is expected. It is now in Setup Done Check for Onkar Kulkarni Sir. If he returns it for fixes, correct the setup and mark it done again.
